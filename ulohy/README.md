# 🎯 Praktické úlohy na precvičenie Gitu a GitHubu

Tento kurz obsahuje **10 praktických úloh**, ktoré ťa krok za krokom prevedú prácou s verziovacím systémom Git a službou GitHub. Úlohy sú primárne zamerané na prácu s grafickými nástrojmi (**GitHub Desktop** a **JetBrains IDE** ako Rider, IntelliJ IDEA, PyCharm, WebStorm).

---

## 🛠️ Čo budeš potrebovať
1. **GitHub účet** – vytvorený na [github.com](https://github.com).
2. **GitHub Desktop** – stiahnutý a nainštalovaný z [desktop.github.com](https://desktop.github.com).
3. **JetBrains IDE** (napr. Rider, IntelliJ IDEA, PyCharm, WebStorm) – so študentskou licenciou cez GitHub Student Pack.
4. **Internetový prehliadač**.
